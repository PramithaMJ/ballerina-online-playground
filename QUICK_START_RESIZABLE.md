# Quick Start Guide: Resizable Panels 🎯

## 🎨 What You Can Do Now

### 1. **DRAG TO RESIZE** 
```
┌─────────────────────┬─────────────────────┐
│                     │                     │
│   Drag me! ═══►     │                     │
│                     │                     │
└─────────────────────┴─────────────────────┘
```
**How:** Hover → See handle → Click & Drag → Release

---

### 2. **SWITCH LAYOUTS**

**Horizontal (Side-by-side):**
```
┌──────────────┬──────────────┐
│              │              │
│   Editor     │   Output     │
│              │              │
└──────────────┴──────────────┘
```

**Vertical (Stacked):**
```
┌───────────────────────────┐
│         Editor            │
├───────────────────────────┤
│         Output            │
└───────────────────────────┘
```

**How:** Click "Horizontal"/"Vertical" button

---

### 3. **RESET TO 50-50**
```
Before:                  After:
┌─────────┬─────────┐    ┌──────────┬──────────┐
│ 70%     │ 30%     │ → │ 50%      │ 50%      │
└─────────┴─────────┘    └──────────┴──────────┘
```
**How:** Click "Reset Split" button

---

## 🎮 Interactive Elements

### **Separator Handle**
- **Color:** Bright teal (#52c3c2)
- **Width:** 4px
- **Hover:** Shows grip icon
- **Drag:** Glows and scales up

### **Layout Toggle Button**
- **Location:** Top bar
- **States:** Horizontal ⇄ Vertical
- **Active:** Teal background
- **Icon:** Changes based on mode

### **Reset Button**
- **Location:** Top bar
- **Action:** Returns to 50-50
- **Works:** In both layouts

## 💡 Pro Tips

### **Tip 1: Quick Resize**
Move your mouse to the center line → Drag instantly!

### **Tip 2: Layout for Task**
- **Debugging?** Use Vertical layout for full-width output
- **Coding?** Use Horizontal with wider editor

### **Tip 3: Saved Automatically**
Your preferences are remembered next time you visit!

### **Tip 4: Safe Constraints**
Can't make panels too small (min 20%) or too large (max 80%)

## ⚡ Keyboard & Mouse

### **Mouse:**
- **Hover** over separator → Handle appears
- **Click** on separator → Start resize
- **Drag** left/right (horizontal) or up/down (vertical)
- **Release** → Set new size

### **Visual Feedback:**
- ✅ Cursor changes (col-resize or row-resize)
- ✅ Handle glows during drag
- ✅ Smooth animation
- ✅ No lag or flicker
